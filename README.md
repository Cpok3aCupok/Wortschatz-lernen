# Wortschatz — тренажер німецьких слів

Застосунок для iPhone (і будь-якого браузера) для вивчення німецьких слів і фраз
у стилі Quizlet / German Galaxy.

- **1374 записи**: 1229 слів і 145 фраз, рівні **A0, A1, A2, B1, B2**, розбиті за темами.
- **Транскрипція IPA** біля кожного німецького слова (з німецького Вікісловника).
- **Озвучка**: записи носіїв мови з Wikimedia Commons (~91% слів). Якщо запису немає
  або це ваше власне слово чи фраза, слово вимовляє синтезатор iPhone.
- **Режими**:
  - **Заучування** — слова по колу, вибір перекладу DE→UA і UA→DE, помилки повертаються;
  - **Картки** — перевертання, свайп «знаю / ще вчу»;
  - **Письмо** — ручне введення німецькою (кнопки ä ö ü ß, підказка по літері, перевірка артикля й опечаток);
  - **Пари** — з'єднати слово з перекладом на час;
  - **Аудіювання** — вибір перекладу на слух або диктант;
  - **Артиклі** — der / die / das (кольори: der синій, die рожевий, das зелений).
- **Інтервальне повторення**: застосунок сам нагадує, які слова пора повторити.
- **Редагування словника**: додавати, змінювати й видаляти слова, транскрипції, теми, рівні.
  Кнопка «Знайти у Вікісловнику» сама підставляє транскрипцію та запис вимови.
- Додавання **списку слів одразу** (наприклад, з Quizlet або нотаток).
- Працює **без інтернету** (записи вимови можна завантажити наперед).
- **Резервна копія** прогресу у файл.

## Як опублікувати і поставити на iPhone (рекомендований спосіб)

1. Створіть новий репозиторій на GitHub і завантажте туди **весь вміст цієї теки**
   (теки `dist/`, `tools/.cache/` та подібні завантажувати не треба — вони в `.gitignore`).
2. У репозиторії відкрийте **Settings → Pages** і в полі **Source** оберіть **GitHub Actions**.
3. Відкрийте вкладку **Actions**. Процес «Публікація на GitHub Pages» збере застосунок
   (1–2 хвилини). Якщо він запустився ще до кроку 2, натисніть **Re-run jobs**.
4. Адреса застосунку матиме вигляд `https://ВАШ-ЛОГІН.github.io/НАЗВА-РЕПОЗИТОРІЮ/`.
5. На iPhone відкрийте цю адресу в **Safari** → кнопка **«Поділитися»** → **«На початковий екран»**.

Після цього Wortschatz має свою іконку, відкривається на весь екран, як звичайний застосунок,
і працює без інтернету. Після кожної зміни в репозиторії сайт перезбирається сам,
а застосунок запропонує «Оновити».

> **Порада щодо голосу.** Параметри iPhone → Доступність → Озвучений вміст → Голоси → Німецька:
> завантажте голос із позначкою «Покращений» або «Преміум» (наприклад, Anna).
> Синтез звучатиме значно природніше.

## Альтернатива: справжній застосунок `.ipa`

Процес **«Збірка iOS (.ipa)»** у GitHub Actions компілює нативний застосунок на macOS-сервері GitHub.
Mac для цього не потрібен.

1. **Actions → «Збірка iOS (.ipa)» → Run workflow** (або він запуститься сам після змін).
2. Коли збірка завершиться, відкрийте запуск і в розділі **Artifacts** завантажте `Wortschatz-ipa`.
3. Встановіть `Wortschatz.ipa` на iPhone через **Sideloadly** (є для Windows) або **AltStore**
   з вашим Apple ID.

Обмеження Apple: із безкоштовним Apple ID застосунок треба переустановлювати **кожні 7 днів**.
З платним акаунтом розробника (99 $ на рік) — раз на рік. Тому для щоденного використання
зручніший перший спосіб (GitHub Pages). Обидва варіанти мають однаковий функціонал.

## Важливо: де зберігаються дані

Прогрес, ваші слова й зміни словника зберігаються **тільки на пристрої**
(у сховищі браузера або застосунку). Час від часу робіть копію:
**Налаштування → Резервна копія → Зберегти файл**. Цим же файлом можна перенести все на інший телефон.

## Для розробки

Потрібен лише [Node.js](https://nodejs.org) 18+, жодних бібліотек встановлювати не треба.

```bash
node tools/build.mjs     # зібрати застосунок у dist/
node tools/serve.mjs     # відкрити http://localhost:5173
```

### Структура

| Шлях | Що там |
|---|---|
| `app/` | Застосунок: `index.html`, стилі, JavaScript (без фреймворків) |
| `app/js/modes/` | Режими тренування |
| `app/js/views/` | Екрани: головний, словник, редактор, налаштування |
| `data/source/A0.txt … B2.txt` | **Вбудований словник** — простий текстовий формат |
| `data/pronunciation.json` | Транскрипції та посилання на записи (генерується) |
| `tools/build.mjs` | Збірка в `dist/` (словник, іконки, service worker) |
| `tools/enrich.mjs` | Пошук IPA та аудіо у Вікісловнику для слів зі словника |
| `ios/` | Нативна обгортка для iPhone (Swift + WKWebView) |
| `.github/workflows/` | Автоматична публікація та збірка `.ipa` |

### Як доповнити вбудований словник

Відкрийте потрібний файл у `data/source/` і додайте рядки:

```
# Тема
der Hund | die Hunde | собака
gehen | geht, ging, ist gegangen | йти
gut | добре

# Фрази: Назва теми
Wie geht's? | Як справи?
```

Формат рядка: `німецькою | форми | переклад` або коротко `німецькою | переклад`.
Іменники пишіть з артиклем. Після змін запустіть:

```bash
node tools/enrich.mjs    # знайде транскрипції та записи для нових слів
node tools/build.mjs
```

І закомітьте оновлений `data/pronunciation.json`.
